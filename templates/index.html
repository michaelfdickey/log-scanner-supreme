📝 Edit Fast Summary Prompts

Edit the prompts sent to the AI for Fast Summary analysis. Use {{variable}} placeholders for dynamic values.

Available variables
  • {{focus_instruction}} — Expanded issue description block (built from focus_instruction_template when user provides an issue description)
  • {{log_type_instruction}} — Auto-detected log type context plus any specific analysis instructions from log_types.md
  • {{log_type_prompt}} — The specific analysis prompt for this log type from log_types.md (empty if no match)
  • {{total_lines}} — Total number of lines in the log file
  • {{error_count}} — Number of pre-scanned error lines
  • {{warning_count}} — Number of pre-scanned warning lines
  • {{condensed_text}} — The condensed log content
  • {{issue_description}} — The user's issue description (used in focus_instruction_template)
